# BDA400 – Assignment 6
## Technical Analysis using R – Visualization Phase

### Project Overview
This project presents an interactive stock technical analysis dashboard developed using R and Shiny. The dashboard retrieves historical stock market data from Yahoo Finance and visualizes stock prices along with technical indicators to help users understand market trends.

### Features
- Historical stock data retrieval from Yahoo Finance
- Interactive stock symbol selection
- Custom date range selection
- Daily, weekly, and monthly data views
- Stock closing price visualization
- Moving Average indicators (MA20 and MA50)
- Relative Strength Index (RSI14)
- Moving Average Convergence Divergence (MACD)
- Buy, Sell, and Hold signals based on moving average crossovers

### Technologies Used
- R
- Shiny
- ggplot2
- quantmod
- TTR
- dplyr
- lubridate

### How to Run
1. Open the project in RStudio or Posit Cloud.
2. Open `app.R`.
3. Make sure the required packages are installed.
4. Click **Run App**.
5. Enter a stock symbol and select your preferred date range and timeframe.

### Data Source
Historical stock market data is retrieved from Yahoo Finance.
