---

**Student Name:** Muhammad Tahir

**Assignment:** Technical Analysis using R – Visualization Phase

### Project Description

This project involves developing an interactive stock analysis dashboard using R and Shiny. The dashboard retrieves historical stock market data from Yahoo Finance and visualizes stock prices through interactive charts.

Users can select stock symbols, date ranges, and timeframes and analyze market data using Moving Averages (MA20 and MA50), Relative Strength Index (RSI), and MACD. The dashboard also generates Buy and Sell signals based on moving average crossover rules.
